# ¡Bienvenido a Antigravity!

¡Bienvenido a tu nuevo hogar de desarrollo! Tu proyecto de Firebase Studio ha sido migrado exitosamente a Antigravity.

Antigravity es nuestro IDE de próxima generación diseñado para el desarrollo autónomo de alta velocidad con agentes. Debido a que Antigravity se ejecuta localmente en tu máquina, ahora tienes acceso a flujos de trabajo locales potentes y capacidades de edición de IA completamente integradas que van más allá de un IDE web en la nube.

## Cómo Empezar
- **Ejecutar Localmente**: Usa el menú **Ejecutar y Depurar** en la barra lateral izquierda para iniciar tu servidor de desarrollo local.
  - O en una terminal ejecuta `npm run dev` y visita `http://localhost:9002`.
- **Desplegar**: Puedes desplegar tus cambios en Firebase App Hosting utilizando la terminal integrada y los comandos estándar de la CLI de Firebase, tal como lo hacías en Firebase Studio.
- **Limpieza**: Limpia los artefactos no utilizados con el flujo de trabajo @cleanup.

¡Disfruta de la próxima era del desarrollo impulsado por IA!

Reporta cualquier error en https://github.com/firebase/firebase-tools/issues
